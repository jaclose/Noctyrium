# AXOM-0002c — Grouped Candidate Packages

## How to read this file

Each package compresses archival evidence into a bounded Product Owner
decision. `FOUND-*` handles are disposable. Candidate IDs point back to the
196-record AXOM-0002b.1 archive, where complete evidence locators and conflict
text remain preserved.

“Suggested relationship” means a relationship between proposals. A permanent
related `AX-` ID cannot be named until the Product Owner approves records and
assigns IDs.

No package assigns an owner-controlled value.
