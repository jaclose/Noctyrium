# AXOM-0002c.1 — Product Owner Decisions

## Decision-record rule

This file records Product Owner language without invention. A recommendation
is not a decision. Conversation may be normalized into a disposition only
when the Product Owner has supplied an explicit response. Silence is never
approval.

Each confirmed record preserves the original proposal, Candidate provenance,
analytical recommendation, exact Product Owner language, normalized decision,
approved temporary wording and routes, exclusions, qualifications, follow-ups,
insertion eligibility, confirmation state, and decision attribution.
