# AXOM Pre-Alpha Release Checklist

## Blocks internal personal testing

- [x] Clean committed baseline builds and tests from documented root install.
- [x] Local canonical workspace, migration backup, reload persistence, import journey, and offline Daily Games have automated evidence.
- [ ] Claude re-runs all Q2a gates and commits only the reviewed Q2a scope.

## Blocks trusted-friend / closed Alpha

- [ ] Remove or explicitly approve identity-specific Drive/Notion/Mega defaults.
- [ ] Disable cloud sync/account surfaces unless all snapshot endpoints require verified session ownership.
- [ ] Fix/document root vs web install; add clean-clone CI.
- [ ] Add automated accessibility scans and manual keyboard/zoom pass on critical populated flows.
- [ ] Unify CSV/JSON answer drift policy or label the limitation prominently.
- [ ] Run destructive backup replace/merge and corrupted-file journeys in disposable contexts.
- [ ] Hide or clearly badge Doctordle, Leaderboards, Application Checker.

## Blocks public Alpha

- [ ] Complete all closed-Alpha items and field-test with several clean user profiles.
- [ ] Restrict service-worker runtime cache; verify two-version upgrade with populated schema-32 workspace.
- [ ] Rename/redirect repository and hosted URL; remove legacy public branding and stale deployment links.
- [ ] Threat model, privacy statement, data deletion/export/recovery, incident contact.
- [ ] Performance budget and mid-range-device import measurements.
- [ ] Release metadata single-source gate and rollback rehearsal.

## Safe to defer to Beta

Accounts/OAuth/sync, institution connectors, OCR, source binaries, curriculum graph, advanced analytics, generated rationales with disclosure, multiple notebooks/search if scope stays honest.

## Safe to defer to Version 2

Journal Cinematic/physics/sound/haptics, broad community school marketplace, advanced proctor simulation, semantic enrichment beyond grounded review.

## Verdicts

- Personal daily use: **GREEN**, with routine JSON backups and cloud disabled.
- Trusted friend testing: **YELLOW**, after privacy-link review and Q2a commit.
- Closed SGU Alpha: **YELLOW**, blocked on security/privacy/accessibility and upgrade rehearsal.
- Public pre-Alpha: **RED**.
- Public Alpha: **RED**.
